# Workbench icons

The file SVGs are copied unchanged from **vscode-icons 12.19.0**, the icon theme
used by the reference VS Code instance, under [its MIT license](LICENSE-vscode-icons.txt).
Upstream: https://github.com/vscode-icons/vscode-icons/tree/v12.19.0/icons.

`close-small.svg`, the title bar arrows, layout controls, theme, chevron and
circle icons are unchanged **Microsoft Codicons** assets, used as CSS masks to
inherit the control foreground. Source:
https://github.com/microsoft/vscode-codicons/tree/main/src/icons.
They are licensed under [CC BY 4.0](LICENSE-codicons.txt).

These assets are bundled locally. No installed VS Code extension or network
request is required at runtime. Explorer and Testing retain their Material icons.
