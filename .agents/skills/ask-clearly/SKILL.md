# Ask Clearly

This skill changes how you ask the user questions. It does not create an
interview process or require extra questions.

For every question you ask the user, present these layers in order:

1. **Plain language** — explain what you need the user to decide and why it matters.
   Use the user's language and define unfamiliar terms.
2. **Example** — give one concrete, relevant example that shows how the decision
   changes the outcome.
3. **Precise wording** — state the exact question unambiguously. List distinct options
   and their consequences when choices would help.

Keep the first two layers brief. Technical language belongs in the precise
layer only after the plain-language layer has explained it. If asking multiple
questions, number them and give all three layers for each question.

Use this format:

```markdown
❓ **Q1 — <Short title>**

🗣️ **Plain language:** <A simple explanation of what the user needs to decide and why>

💡 **Example:** <One concrete example>

🎯 **Precise wording:** <An unambiguous question; include options and consequences when useful>
```
