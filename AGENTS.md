# AGENTS

- Any code modification in this repository must use `husky-di-code-standard`.
- When a change introduces or expands public, user-visible behavior, update the
  normative specification and the matching `specification.test.ts` coverage in
  the same change. Do not treat spec and spec-test updates as optional follow-up
  work.

## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Local issue statuses use the default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.
